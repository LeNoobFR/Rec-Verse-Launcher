# RecVerse Launcher

A launcher for launching RecVerse more easily.

## Features

- **Installing / Updating:** Downloading and Updating RecVerse more easily.
- **Installation Folder:** Choose where RecVerse is installed.
- **Download Link:** Change the download link directly from the launcher.
- **Saved Settings:** All of the change that you make are saved.

## Requirements

- WinRAR

## Installation

1. Download the launcher from the release tab.
3. Run the launcher.
4. Select **Install / Reinstall RecVerse**.
5. Wait for the download and the extraction to finish.
6. Then launch the game by selecting **Launch RecVerse**

## Diagnosing

**WinRAR was not found**
- Install WinRAR and launch the launcher again.

**Download failed**
- Check your internet.
- Check that the download link is correct.

**Screen or VR Files is missing**
- Select **Check installation**.
- Check that the `.bat` exists in the game folder.
